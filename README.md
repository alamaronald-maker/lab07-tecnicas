# lab07-tecnicas

## Bitácora de técnicas avanzadas de prompting

**Laboratorio 07 – Técnicas Avanzadas de Prompting**

### Descripción

Este repositorio contiene el desarrollo de los ejercicios del Laboratorio 07, aplicando diferentes técnicas avanzadas de prompting mediante la herramienta ChatGPT.

### Ejercicios desarrollados

- Ejercicio 2: Zero-shot, One-shot y Few-shot.
- Ejercicio 3: Chain of Thought.
- Ejercicio 4: Role prompting.
- Ejercicio 5: Descomposición.
- Ejercicio 6: Prompt estructurado y autocrítica.
- Ejercicio 7: Publicación de la bitácora en GitHub.
